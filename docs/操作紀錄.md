# Unity 操作與驗證紀錄

作業日期 2026-11-13。目標為把原劍龍與灌木森林移入 Unity，做成可個別編輯的零件、場景及五鏡頭影片流程。專案版本固定為 Unity 6000.3.28f1，使用 Built-in Render Pipeline。

## 已執行的製作

1. 核對來源資產。角色取自原專案的 `stegosaur_actions.blend`，森林取自原專案的樹木、灌木和落葉地表素材。環境光採可追溯至 Poly Haven 的 Forest Slope HDRI。
2. 用 Blender 4.5.3 LTS 將劍龍 FBX 拆成 23 個有名稱的蒙皮網格。頭頸、軀幹、四足和尾巴共 7 件，另外有 11 塊背板與 5 支尾刺。各零件保留權重、UV 和邊界法線，組裝後使用同一副 35 骨骨架。
3. 匯出 `Walk`、`Run`、`HeadShake`、`Roar_Pose` 四個骨架動作。把闊葉樹、松樹苗、樹樁和五個灌木變體各自轉為 FBX，落葉色彩、法線和材質貼圖分開匯入。
4. 以 `ForestSceneBuilder` 定義森林。它根據素材清單建立材質、Prefabs、分件 Mesh 資產及 `StegosaurForest.unity`。落葉地面、植被、光照和角色各有自己的階層。
5. 以 `ForestRender` 實作逐格骨架取樣和鏡頭，將各段寫成連續 PNG。PowerShell 包裝腳本負責啟動 Unity、編碼 MP4 及檢查輸出。

模型與貼圖、場景組裝、鏡頭與輸出三組分工在各自的 Git 工作樹完成，由主流程整合。素材來源見[素材來源與授權](素材來源.md)。

## 2026-11-13 實際操作

1. Unity Hub 授權啟用後，啟動 Unity 6000.3.28f1（`8f082d2fe476`）的批次 Editor。使用 Direct3D 11、AMD Radeon RX 6800 XT 和專案的 Gamma 色彩空間。Editor 完成匯入、編譯並儲存 `StegosaurForest.unity`，場景包含 9 個獨立模型 Prefab 和 23 個劍龍蒙皮零件。
2. 第一次試渲染停在動畫選取。FBX 載入結果同時有正式片段和 `__preview__` 片段，令 `Walk` 匹配兩次。把動畫查詢改用 `LoadAllAssetRepresentationsAtPath` 後，四段正式動畫均可取樣，第二次試渲染輸出 15 張畫格。 [Unity 的可見子資產 API](https://docs.unity.com/en-us/engine/6000.3/script-reference/unityeditor/assetdatabase/loadallassetrepresentationsatpath)
3. 檢視這 15 張畫格時發現劍龍小到看不見。診斷比對了 FBX 原始蒙皮、烘焙後的局部網格，以及世界變換，發現 100 倍的 FBX 子物件比例被重複計入尺寸，導致角色根層只剩約 0.01921 倍。修正 `BakeMesh` 的比例參數後，場景根層比例約 1.92092。重建場景並試渲染，五個鏡頭均看得到劍龍。
4. 依畫格加了一盞低強度補光，提亮走路和甩頭鏡頭的陰影。奔跑鏡頭稍微後退並把取景往前移。重建場景後，以 640×360 重跑預覽，逐鏡頭檢視起、中、末共 15 張畫格。
5. 執行完整渲染。Unity 輸出 300 張 PNG，FFmpeg 9.0.1 以 `libx264`、`yuv420p` 和 CRF 18 編碼成 12.5 秒的 MP4。檔案為 34,352,317 bytes，含一條影像串流，無音軌。FFmpeg 完整解碼、FFprobe 計數和黑畫面掃描均通過，並由另一位代理從成片抽查每鏡頭三格。 [MP4](../media/stegosaur-forest-unity.mp4) · [成片抽格](../Evidence/shot-contact.jpg)

## Unity Editor 重現

1. 在 Unity Hub 啟用授權，新增此 repo 根目錄為專案，使用 6000.3.28f1 開啟。
2. 開啟 `Assets/Scenes/StegosaurForest.unity`。如需重建場景，可選 **Dinosaug → Build Forest Scene**。展開 `Stegosaur` 檢查分件、骨架與裝配。可從 `Assets/Generated/DinosaurParts` 選取個別 Mesh，或從 `Assets/Generated/Prefabs` 選取環境 Prefab。
3. 調整物件位置、尺度或材質後儲存場景。執行 **Dinosaug → Render Forest Smoke Test** 預覽各鏡頭的起、中、末三幀。完整出圖執行 **Dinosaug → Render Forest Film**。
4. 角色與森林的輸出會寫入 `Render/` 下的新目錄。建場景會重建同名場景和生成資產，日常調整後直接儲存場景並渲染即可。

## Windows 批次渲染

使用 PowerShell，從 repo 根目錄執行。以下為本次執行的 Editor 路徑。其他電腦請依安裝位置調整。

```powershell
$unityExe = 'C:\Program Files\Unity 6000.3.28f1\Editor\Unity.exe'
& .\Tools\Render-UnityForest.ps1 -UnityExe $unityExe -Smoke -Width 640 -Height 360
& .\Tools\Render-UnityForest.ps1 -UnityExe $unityExe
```

## 從原素材重做分件

如果已持有原灌木森林專案資料夾及 [Forest Slope 1K HDRI](https://polyhaven.com/a/forest_slope)，可執行 Blender 轉檔工具。請在單獨的專案副本操作，轉檔工具會重寫素材清單和 FBX。GitHub 內已附可直接匯入 Unity 的轉檔成果。

```powershell
& $blenderExe -b --python-exit-code 1 --python .\Tools\prepare_unity_assets.py -- --source $forestSource --sky $forestSlopeHdr
```

`$forestSource` 應含 `stegosaur_actions/stegosaur_actions.blend` 和原版 `assets/`。轉檔完成會寫出 `Assets/Source/asset-manifest.json`，並用 Blender 重新匯入 FBX 驗證。素材轉檔當天的報告保留於 [Evidence/asset-check.json](../Evidence/asset-check.json)。
